# Mi Finanzas

Aplicación Android de finanzas personales, offline-first: ingresos, gastos, presupuestos,
ahorros y deudas guardados localmente con SQLite. Sin cuentas ni nube.

**Stack:** React Native · Expo SDK 58 · TypeScript · Expo Router · expo-sqlite

```bash
npm install
npm run android     # abre en emulador/dispositivo Android
npm run typecheck
npm run lint
```

Arquitectura y hoja de ruta: [docs/ARQUITECTURA.md](docs/ARQUITECTURA.md).
